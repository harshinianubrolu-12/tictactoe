#TICTACTOE

●	Developed a dynamic, interactive Tic Tac Toe web application using React, leveraging the modern build tool Vite for an optimized development experience.
●	Developed functionalities like player customization, interactive game board, result notification and game reset.
●	Adhered to high coding standards by modularizing the application, creating reusable components for scalable and maintainable code architecture.
●	Ensured efficient state management by minimizing the usage of state variables and implementing state lifting, promoting smoother state synchronization across components.
